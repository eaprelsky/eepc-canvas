# eEPC Canvas

Лёгкий редактор бизнес-процессов в нотации **ARIS eEPC** (extended Event-driven Process Chain). Отдельное веб-приложение без бэкенда: диаграммы хранятся в JSON-файлах, редактор открывает и сохраняет их локально.

## Почему это приятно смотреть

Редактор целенаправленно следит за эстетикой схем — даже у «криворуких» пользователей результат получается чистым:

- **Фигуры на сетке** — все координаты и размеры кратны 10 px; перемещение с привязкой к сетке.
- **Никаких наложений** — автораскладка резервирует полосы под роли, документы и системы; при ручном перетаскивании элемент сам ищет ближайшее свободное место.
- **Линии входят точно в фигуры** — стрелки начинаются и заканчиваются ровно в центре границы, у каждой точки входа/выхода свой порт.
- **Прямые линии остаются прямыми** — цепочки выравниваются по вертикали по центру предка (даже при разной ширине фигур), порты всегда в центрах, микро-ступеньки короче 20 px устраняются автоматически.
- **Выверенные изгибы** — там, где нужен поворот, стрелка делает ровно два скруглённых поворота на общей линии канала: изгибы соседних стрелок коллинеарны, как рельсы.
- **Ортогональная маршрутизация с обходом** — связи идут по вертикалям и горизонталям, огибают фигуры и стараются не накладываться друг на друга (A* по сетке со штрафами за повороты и занятые клетки).
- **Слоевая авторазкладка** — «Упорядочить» раскладывает процесс сверху вниз по слоям с минимизацией пересечений (алгоритм Сугиямы: слои, виртуальные вершины, барицентры).
- **Надписи по центру и с воздухом** — оптическое центрирование по базовой линии, отступы от границ калиброваны по каждому типу фигур, перенос строк сбалансирован (без «висячих» предлогов и строк-сирот), максимум 3 строки.
- **Роли и документы в ряд со своей функцией** — первый привязанный элемент всегда в ряду функции, стопка идёт вниз с шагом 100 px.
- **Живая проверка нотации** — редактор подсказывает правила eEPC: процесс начинается и заканчивается событием, два события подряд нельзя, у события и функции один вход и один выход, ветвление только через XOR/OR/AND, роли/документы/системы привязываются только к функциям.

## Элементы нотации

| Элемент | Обозначение | Связь с функцией |
|---|---|---|
| Событие | шестиугольник | — |
| Функция | зелёный прямоугольник со скруглением | — |
| Ветвление XOR / OR / AND | кружок с подписью | — |
| Роль | жёлтый овал с вертикальной полосой | линия без стрелки |
| Документ | прямоугольник с волнистым низом | стрелка (в функцию / из функции / двусторонняя) |
| Система | прямоугольник с двойными боковыми границами | стрелка (в функцию / из функции / двусторонняя) |

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev        # http://localhost:5173
```

Продакшен-сборка:

```bash
npm run build      # dist/
npm run preview
```

Тесты (инварианты раскладки и маршрутизации, правила нотации):

```bash
npm test
```

## Формат файла

Диаграмма — обычный JSON (обычно с расширением `.eepc.json`):

```json
{
  "format": "eepc-diagram",
  "version": 1,
  "name": "Обработка заказа",
  "nodes": [
    { "id": "e1", "type": "event", "label": "Поступила заявка" },
    { "id": "f1", "type": "function", "label": "Обработать заявку" },
    { "id": "g1", "type": "gateway", "operator": "XOR" },
    { "id": "r1", "type": "role", "label": "Оператор", "attachTo": "f1", "side": "right" },
    { "id": "d1", "type": "document", "label": "Заявка", "attachTo": "f1", "side": "left", "dir": "in" }
  ],
  "flows": [
    { "id": "fl1", "from": "e1", "to": "f1" },
    { "id": "fl2", "from": "f1", "to": "g1" }
  ]
}
```

- `x` и `y` у вершин основного потока необязательны: без них диаграмма раскладывается автоматически. После «Упорядочить» координаты сохраняются в файл.
- Роли, документы и системы не имеют собственных координат — они всегда следуют за своей функцией (`attachTo`, `side`).
- Примеры лежат в [examples/](examples/).

## Десктоп-приложение для Windows

```bash
npm run build:desktop
```

Собирает веб-версию и упаковывает её в нативное окно на [Neutralino](https://neutralino.js.org): оболочка весит ~2.5 МБ и рендерит системный WebView2, тянуть Electron или отдельный браузер не нужно. Итог — `desktop/dist/eepc-canvas/eepc-canvas-win_x64.exe` (рядом с ним должен лежать `resources.neu`); готовый архив лежит в [Releases](https://github.com/eaprelsky/eepc-canvas/releases). Первый запуск сборки скачивает бинарники Neutralino (~8 МБ), дальше сборка идёт без сети.

## Встраивание в веб-приложение

Ядро (модель, валидация, раскладка, маршрутизация, рендер) не зависит от UI-фреймворка и живёт в `src/core`. Два способа встроить:

**1. Готовый редактор одним скриптом** (сборка `npm run build:embed` → `dist-embed/eepc-canvas.js`):

```html
<script src="eepc-canvas.js"></script>
<div id="editor" style="height: 600px"></div>
<script>
  const diagram = EepcCanvas.parseDiagramJson(jsonText).diagram;
  EepcCanvas.mount(document.getElementById('editor'), diagram);
</script>
```

**2. Только рендер готовой диаграммы** (без редактора):

```js
import { parseDiagramJson, autoArrange, renderLayouted } from './core';

const { diagram } = parseDiagramJson(jsonText);
const layouted = autoArrange(diagram);          // или layoutDiagram(diagram) с сохранёнными позициями
document.body.appendChild(renderLayouted(layouted));
```

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Z / Ctrl+Y | отменить / повторить |
| Ctrl+S / Ctrl+O | сохранить / открыть |
| Delete | удалить выбранный элемент |
| Esc | сбросить инструмент / выбор |
| Стрелки | сдвиг на шаг сетки (Shift — крупнее) |
| Колесо мыши | масштаб; пустое место — панорама |

## Структура

```

src/app      редактор: канва, палитра, инспектор, тулбар, история правок
examples/    примеры диаграмм
```
